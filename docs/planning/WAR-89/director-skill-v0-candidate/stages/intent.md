# Intent：决定观众怎样经历这一场

进入时要有剧本关键原文、已确认意图/禁项、可调整空间和证据来源。修订时另带当前批准 Intent、用户改变什么与未授权改变什么。缺的是作者事实就回读；缺的是开放拍法就提出候选，不把每个自由细节变成审批请求。

## 从认知弧线到表达政策

先说开场观众凭什么理解处境；中段何事使他重新判断人物或期待；结尾留下什么未说出的后果。区分角色知道而观众不知、观众先知、同步发现。心理解释要有行为/原文支持；“羞愧源于往事”若无出处只是新故事，不是导演细化。

随后选择整场政策，使后续不同镜头仍指向同一种体验。例如，让观众观察两人之间的距离变化，适合保留共同空间及反应余量；让观众贴近一方的迟疑，适合限制信息和主观听感。前者可能牺牲微表情，后者可能过早将客观事实归属给角色。只有这些体验确实竞争时才比较，不机械出三套风格。

用政策约束选择：注意力主要跟谁走；何种信息暂缓；表演幅度如何支持关系；何处让声音推动、何处留给沉默；镜头运动怎样才有理由。把“倾向保留关系”与“用户明确禁止某种行为”分开。倾向可在局部说明代价后偏离，批准禁项必须上行。此处不预制焦距/镜表，也不靠“高级、克制、电影感”代替可观察选择。

## 审阅 A 的实际交接

给用户一段可想象的观众经历，附选定政策、最有意义的替代及损失、不可改的源事实、开放风险。A 确认的是方向，不是所有镜头或真实效果。批准后向 Beat 交付认知先后、需要表达的转折、声音与表演政策及其理由；未批准时保持 Intent 候选身份。

反例：靠一个提前揭示的特写“加强悬念”，却改变了作者指定的信息延迟；把克制写成任何人都不许动；给未写的亲属关系定性。前者回 K1/K2，后两者回 K1/K3。按 [知识索引](../references/knowledge-index.md) 查 DS-01/02/06 与 TF-02；已有清楚弧线和可用政策即停，不导入完整 Director's Book。
