# Shot Plan：先决定观众此刻得到什么

输入不能只有动作 ID 或焦距。需要批准 Intent 及理由、全场 Scene Spine、目标及相邻 Beat、Blocking 起始/中间/终态、原话与声音时序、一个活跃候选和差异、真实参考覆盖及未证项。缺相邻状态时可给隔离草案，不能宣称接缝已检查。

## 选择观看方法

先给每镜一个可检验任务：观众从哪里看起，经哪个动作或声源转移注意，最终新知道/仍不知道什么？同时写此时人物知道什么。将“桌上存在”与“镜内足以认出”分开。

当线索与关系争夺注意时才比较：关系镜用纵深/调度/焦点维持表演连续，代价是线索大小和竞争注意；客观细节镜分配明确阅读机会，代价是强调过强、失去人物同时反应、可能造成错误 POV 联想；反应镜让后果成为主体，但可能推迟应同步交付的事实。选能守住本场信息政策的一种，不因术语更华丽选择。客观镜接人物反应并不自动等于 POV，也不能仅靠标注“客观”消除眼线剪接造成的主观暗示。

决定后才构造画面：摄影机相对关系轴哪侧、与人物眼位及物件的高低/距离；景别保留哪些身体和环境线索；前中后景何者清楚、何者不得抢注意；固定、移动或变焦的起落点；演员动作经过哪些中间态。焦距服务裁切与距离选择，不是情绪保证；浅焦若遮掉需要同时看见的事实，应改深度安排或拍法。

## 构造观看的时间

把动作展开为观众寻找主体、辨认信息、将信息关联到人物处境的机会。写清注意窗口从哪一刻开始、被什么事件关闭；不凭一个“清晰可见”断言成功。若窗口只有物理露出但被另一个强动作抢走，返回 Blocking 调整，或换镜头承担。

切点是观看任务的转交：动作中切需接续当前阶段；在反应前切是等待，在反应后切是消化，二者代价不同。声音提前/延后必须保住真实声源及故事顺序；持续环境声可保持空间感，不能替错误持物或重复动作遮丑。允许有意时间省略，但要声明跳过什么、为何不损害必需的决定及因果。

新角度、物体背面、文字或手部细节可能缺参考。分别写“故事规定什么”“本镜需交付什么”“素材实际支持什么”。缺素材可保留拍法，不能自动添参考图、Camera Tree、FF/LF 或 H3 控制项。没有真实资产就直说没有。

## 提交一个可继续工作的候选

给逐镜任务与 construction、少量真替代及放弃理由、动作/对白/声音覆盖、切点与邻镜状态、具体未证项。若回 Blocking，明确需要改变的行为和不允许改变的事实，待新候选回来后实际改镜头，不把“建议修复”记成“已修复”。

局部复检从直接依赖到邻镜、首次知情窗口、全场交付责任；整场 B 才做完整双向覆盖。失败反例：细节镜让观众先知道了本应延后的信息；裁切只见手却声称已交付面部反应；连续切重演一次递物；旧候选已失效却沿用“已检”。依 [review-method](../references/review-method.md) 区分文本冲突和媒体未知。K5 主导，信息差查 K2、动作问题查 K4/K6、修订查 K7，源边界查 K1；停止条件见 [知识索引](../references/knowledge-index.md)。
