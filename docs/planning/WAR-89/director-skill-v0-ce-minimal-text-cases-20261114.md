### C 最小任务与可评阅范围

从该原文为 L16–26 设计可执行的 Beat/Blocking/Shot 候选，交代观众如何看出陈主动收住、许听懂却不替他说。提供一项真正替代及代价、相邻声画顺序、证据未知。前段 L7 的第一次广播与 L11–15 对话作为已发生的上下文，若扩写整场则逐字保留；末端许离开、陈不追不叫住必须承接。当前无正式批准 Intent；可提出克制表演方向作为候选，不得伪造 A/B 批准。

关键语义以 L17–24、30–35 为准：陈实际全部话语就是「过年的时候……」，自行停句；许已听懂不是待核事实；她不直接回答，也不替他说完；第二次广播只能在陈后续「嗯。」之后。第一次模糊广播不授权在停句处再加一次打断。

| 严格失败信号（文本可判） | 允许的不同拍法（不自动代表有效） |
| --- | --- |
| 第二次广播在半句话尾进入，或明确因广播让陈说不下去；把自主停句写成剪辑删掉后半句 | 陈话尾留在本人镜头，或原声跨到许的反应，均使自主收住可理解；不可用声音因果改变角色选择 |
| 许问“你想说什么”、替他补“你还会回来吗”或声称她没有听懂 | 许转头与短暂停顿后说原话；理解可由目光、呼吸或微小姿态承载，不要求放大情绪 |
| 把克制当完全不动而删许转头/离开；添加哭泣、拥抱或追上去 | 关系镜保持两人反应，或陈近景→许反应；前者空间完整但微表情难读，后者焦点明确但有机械反打风险 |
| 以“静默”为由删两次广播，或给二人关系/离开原因/未来补定论 | 可不用配乐、降低非必要声层，但保留自然声场及两次广播顺序；关系保持原文开放 |

待证：微表演是否可辨、广播声源/音量是否让首看观众误归因、自然对白和反应容量。正确原文次序只是必要条件；若实际声画仍让人以为被打断，要据真实证据修订。没有图像/声音资产（L36），没有本轮实测记录。

### E 最小任务与可评阅范围

从该原文为 L15–36 设计信息揭示和结尾行为的候选，保留 L9–13 整理/准备离开的场景上下文。比较同镜翻面与客观背字插镜怎样服务同步首次阅读；说明翻面开始、可读窗口、人物反应与最终落放的连续关系，标素材缺口。当前无正式批准 Intent；任何候选意图不冒充批准。林是女、周是男（L5），不能借用 D 的同名角色设定。

| 严格失败信号（文本可判） | 允许的不同拍法（不自动代表有效） |
| --- | --- |
| 翻面前已让观众读到「我们一定会回到这里」等足以表达过去承诺的片段，即使遮住日期/未露全文 | 家庭合影正面先自然出现；翻面经过的背部仅不可辨纹理、或不足以传达核心语义的片段，不自动判为泄露。实际片段能否泄露须看媒体 |
| 观众先于林看清背字；或林已读完/说「那时候我们真的这么想。」才给观众全文 | 同镜翻面后安排双方同步首次阅读；也可在字面首次转到可读方向时切背字插镜，不能让林在被切掉的时间里先读完 |
| 用概括字幕/角色旁白替代原字；删改「我们一定会回到这里。——2006年夏」 | 文字准确呈现的方法留待制作选定，导演先保留准确目标及阅读/反应窗口；不据模型能力擅改剧本 |
| 结尾照片被收入相册、收起或改成决定留房子；只给背字特写而漏翻回正面、放相册旁 | 回关系镜看完整落放，或细节镜见正面朝上且与相册空间关系明确，再让两人沉默；不要求固定镜数 |
| 为铺伏笔另造关键照片、过去回忆、搬家原因或未来决定 | 同一张家庭合影因背字得到重释；周此前已知，林/观众翻后首知。L15 是另一张普通照片被收起，不得误写成全场只有一张普通照片 |

同镜方案保留手、阅读者与关系，但字迹和表情争画幅；背字插镜便于明确文字任务，却可能延迟观众获知并脱离实际翻面，要核对切点。两者是允许多解，不是评分答案。同步首次阅读指双方获得文字的时点，不要求逐字眼动同步或设毫秒阈值。
