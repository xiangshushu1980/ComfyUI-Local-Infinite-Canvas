**候选定位。**以下依据 `case-source.txt` 与本目录候选 Skill 的四阶段卡推演，属于**探索方案，Intent 与整场 Plan 均未获用户批准**。约 30 秒是节奏目标，不以压短必要沉默为代价。本轮只做文本规划；人物、空间和镜头均无媒体验证。

**一、Director Intent：让观众看见一次被听懂、却没有得到回答的询问。**

开场先让观众理解“一个人要走，一个人在送”，从日常叮嘱进入两人的亲近，不要求观众辨认他们是什么关系。陈说天气时，观众还可以把他理解为不放心；直到“过年的时候……”自行停住，前面的关照才显出另一层意思：他一直在接近“你还回来吗”。

关键变化不只是陈没说完，而是许**转回来、接住他的注视，有机会回答，却说了另一句话**。她的“你照顾好自己”既是关心，也结束了这个没有成形的询问。结尾让观众留在陈所在的位置，看着共同空间变成他独自占据的空间；留下的是“没有问下去，也没有叫住”，不替作者判定永别或重逢。

据此选择：

- 注意力从两人的日常关系，逐渐收束到他们之间的等待，最后留给陈与离去的许之间增加的距离。
- 核心交流保留在同一个双人镜头里，让观众同时判断“他在等什么”与“她怎样回应”，不用剪辑替任何一方宣布内心。
- 不安排流泪、苦笑、抚摸票面等额外情绪标记。车票只是陈手里的物件，不承担目的地、归期或身份线索。
- 不配乐，不做主观消音。第一段广播建立车站，第二段广播出现在“嗯”之后；绝不让广播解释陈为何停住。
- 摄影机固定，变化主要来自注视、身体转向和离开。

**有实质差别的表达替代：全场贴近陈。**许的回应主要以画外声出现，画面停留在陈等待与接受的脸上。这样更容易让观众感到他的失落，也更有个人体验的强度；代价是许“听懂后选择不答”的行动缺少直接观察机会，容易被读成她没理解，或被陈的受伤感预先定义为冷淡。本候选选择保留她的回应空间。

**二、Beat：四次理解变化，不对应四个镜头。**

| Beat／参考时间 | 事件、关键时点 | 观众理解的变化与交接 |
|---|---|---|
| 1．叮嘱尚能维持日常，0—6 秒 | 模糊广播、两人短暂沉默。陈：“到了以后，记得给我发个消息。”许：“好。” | 从两个并肩站着的人，理解为亲近者的告别。尚不知道离开的原因，也不能凭谁拿票判断谁乘车。 |
| 2．话题开始接不上，6—13 秒 | 许看向检票口。陈：“那边冬天挺冷的。”许：“我知道。”陈低头看车票，再抬头看许。 | 她的注意已经朝向离开的方向，他仍在维持谈话。低头再抬头是进入下一句的准备，不处理成发现票面信息。 |
| 3．问题被收住，回应换了方向，13—23 秒 | 陈：“过年的时候……”自行停住；**停住后**许转头看他。短暂沉默。许：“你照顾好自己。”陈看着她，轻轻点头：“嗯。” | 观众先期待下文，再发现许已经接收到这句话的分量；她用关照代替答复。陈的“嗯”承接她说出的关照，不证明他获得了关于归期的答案。 |
| 4．仍可叫住，但没有，23—30 秒 | 第二次远处广播；许转身走向检票口。陈留在原地，没有叫住她。 | 未完成的询问成为一次实际放过的机会。离开已经发生，未来仍未知。 |

人物知情不做悬疑处理：陈知道自己想问什么；许听懂是源材料确定的事实。观众能否从上述言语与反应准确理解到“是否回来”，则仍是表达效果的待证项。

**三、Blocking：把“听懂但不回答”排成可执行的过程。**

空间先作一个明确的拍摄假设：立柱在两人身后偏侧，检票口在他们前方偏许的一侧；许站在靠离开通路的位置，陈在内侧，相距约半臂至一臂，不接触。两人起初身体大致朝向候车区，许转身离开时不必绕过陈。检票口的具体建筑与标识没有素材支持，此处只确定方向和通路。

陈暂定以左手将车票自然握在腰部附近；全过程不换手、不递票、不摊开展示。许的小包保持背着，不增加整理行李的动作。这些是连续性候选，不是新增作者事实；尤其不解释车票为何在陈手里。

动作按以下次序执行：

1. **开场与第一句。**两人站定，先留一小段共同沉默。陈向许说叮嘱，许简短答“好”，不刻意躲眼神，也不把回答演成安慰。
2. **许转向检票口。**答完“好”才把视线转过去。陈说天气时仍关注她；她说“我知道”时可以继续望着检票口。此处先不表演拒绝，只完成一个事实性的回答。
3. **陈准备问。**陈低头看手里的票，手不抬起；随后抬头，目光落在许脸上，说“过年的时候……”。最后一个字结束后，嘴合上，视线暂留在她身上。不要再作一次明显张口动作，免得演成正要续说却被截断。
4. **许接到未完的话。**陈停住后，她才从检票口方向转回来，看他的脸；转完后保留一次真实的等待。她不是立刻替他接话，也不先摇头。随后仍看着他说：“你照顾好自己。”
5. **陈接受这句回应。**他维持看她，轻轻点头，说“嗯”。不低头把脸藏掉，不挤出笑容，也不借点头暗示双方已经约好未来。
6. **离开。**“嗯”结束，第二次广播才进入。许先把注意转向检票口，身体随之转过去，再迈步；陈脚位不变，视线随她离开，不抬手、不追、不叫。广播与离开相邻，但不编造“末班催促”或具体车次。

**从 Shot 返回 Blocking 的局部候选修订。**最初设想许只转头、肩膀完全朝检票口。落实关键双人镜时，这会让她接住陈目光后仍保持较强的身体离开姿态，既压缩面部观察机会，也可能把“不直接回答”提前演成“急于摆脱”。

当前候选因此改为：**许转头接住陈目光后，近陈一侧的肩膀自然随转少许，双脚仍留在原位；说完关照、得到“嗯”后才整体转身离开。**不加靠近、触碰或回头，不改变她的去向与知情。

影响集中在第二镜的回应和第三镜的离开起态。文本复检：许仍在陈停住后才转来，沉默仍在她的台词之前，广播仍在“嗯”之后；第三镜必须从她尚未转身的状态接起。此修订已纳入下面镜表，身体角度能否自然、会不会增加过多温柔意味，尚待表演验证。

**四、Shot Plan：三镜，核心交流不拆。**

时间为试排窗口；各镜以事件完成为切点，不按秒数硬切。

**Shot 1｜约 0—10 秒：让普通叮嘱先成立。**

- **观众任务：**认出候车区里的两个人正在告别，并看到许开始把注意转向离开的方向。不要先给观众一个“关系破裂”的结论。
- **构造：**固定双人中全景，摄影机在两人前方略偏许一侧，接近人物眼高。陈在画面左、许在右，立柱在两人后侧，不切割脸或遮住身体。画面右侧留出离开方向。背景人数少，活动不穿过两张脸之间。
- **表演与声音：**先听到远处模糊广播，两人短暂沉默。完整保留：“到了以后，记得给我发个消息。”“好。”许看向检票口；再完整保留：“那边冬天挺冷的。”“我知道。”第一段广播在这些日常交流中自然结束，之后仍有低水平候车区环境声。
- **切点与邻镜：**“我知道”结束，切到更近的双人画面；切时陈尚未低头、许仍望检票口，票还在陈腰部附近。不在此镜提前起低头动作，避免邻镜重复。

**Shot 2｜约 10—24 秒：完整观察一次等待怎样成为告别。**

- **观众任务：**先跟随陈准备开口，再从他的自停转向许的接收，最后看见她以关照代替回答，而陈没有追问。
- **构造：**同轴侧的固定双人中近景，保持陈左许右。摄影机更靠近两人，但不挤成两张脸的拼接；画面下缘留到陈持票的手附近，上部同时保留两人的脸。用能让两张脸都可辨认的景深，不靠拉焦在两人之间裁决谁更重要。立柱仅保留少量作为空间接续。
- **连续过程：**陈低头看票、抬头看许，说“过年的时候……”。镜头不切，他自行收住。许转头、肩膀轻随，接住目光；两人安静地等待约一个呼吸，再由她说：“你照顾好自己。”陈看着她，轻轻点头：“嗯。”
- **关键窗口：**从陈停止发声到许开口，必须足以容纳“她转来—两人确实面对—她没有接着回答”三个阶段。先按约两秒试排，不能把两秒当成有效表演的证明。她说话时陈也仍在画面内，观众可以看到回应落到他身上。
- **声画与切点：**这一整段不引入第二次广播，不切票面，不用反应特写替台词制造中断。“嗯”说完，保留短暂的共同停留；两人均未开始离开动作时，切回宽景。此镜交付的是答非所问已经发生，不是许已经离开。

**Shot 3｜约 24—30 秒：让距离增加，把未说的话留在原处。**

- **观众任务：**确认许走了，陈仍有叫住她的机会，却没有行动；不制造未来结局。
- **构造：**回到第一镜的固定机位与景别，维持人物左右和检票口方向。起幅仍能看见二人，随后许沿右侧通路向景深走，陈与立柱留在原位。摄影机不跟随许，也不推近陈。
- **表演与声音：**先接住上一镜两人尚未转身的状态，第二次远处广播响起。许转向检票口、转身、迈步。陈只以目光跟随，票的位置和持手不变。没有新增对白。
- **收尾：**看见许连续走出几步、二人距离确实增加后，仍给陈一小段不叫住的时间再结束。许不必出画，更不必拍到过闸或上车；这场只承担“朝检票口离开”。广播保持远处、模糊，不增加可辨认的车次、目的地或催促内容。

**最有争议的镜头选择：第二镜坚持双人连续观看。**

它的理由不是“长镜头更克制”，而是这场最重要的信息存在于**一个人停止之后，另一个人如何占用接下来的时间**。两人同框，让陈的等待与许的选择共享同一段时间，也使“话确实由陈自己收住”有直接的声画依据。

真实替代是：保留陈说完并自行停住的完整画面，之后才切许的近景，看她转来、等待、说“你照顾好自己”，再回陈点头“嗯”。这样许的细微反应更容易辨认，观众也较容易读到她在回避回答；代价是剪辑会主动标出她的决策，容易把关照变成一个经过强调的拒绝，并失去她说话时陈同时接收的表演。

本候选暂留双人镜。若实际观看只读到“普通道别”，应先检验许转来后的观察窗口与表演是否成立；若面部信息在合理构图下仍不足，再采用上述近景替代。不能靠补一句解释性台词修复。

**五、精简 Review。**

**确定文本冲突：**当前候选未发现。七句原台词均完整保留；“过年的时候……”之后是陈自停、许转头、沉默、许关照、陈点头与“嗯”，第二次广播随后才来。没有增加关系身份、离开原因、归期、拥抱、追赶或车票交接。票在陈手里而许离开，是原文状态，不擅自补成“递票后送她走”。

**可信规划风险：**

- 双人镜同时保留脸和持票的手，会限制面部大小；若过分追求票清楚，核心交流反而变弱。票不需读出文字，表演优先。
- 许的肩膀转向可使回应更可见，也可能显得过于亲密；宜是自然接话的幅度，不成为靠近动作。
- 沉默太短，像例行道别；太长或陈持续强烈盯视，像逼迫回答。约 30 秒的目标必须保住核心等待和结尾距离，不能只剩完整台词。
- 第二次广播若过响、内容过明确，会把离开解释成外力打断；当前仅用它恢复公共空间的存在感。

**需要媒体或观众验证的未知：**同框能否同时读清两人的反应；“过年的时候……”是否被理解为询问回来，而非一般节日话题；许的关照能否被读成“听懂但不直接回答”，而非没听懂或冷漠；末镜的距离与停留能否让“不叫住”成立，而不暗示永别。以上均未验证，文本上的合理性不等于成片效果。

本轮的审阅对象是一条完整候选：**用共同时间呈现未获回答的询问，再用真实增加的距离结束告别。**它已完成四阶段的文本推演与局部修订，仍保留为未批准方案。
