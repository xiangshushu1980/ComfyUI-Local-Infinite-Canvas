以下为**探索候选 E1，未获用户批准**。依据仅为本目录 `case-source.txt` 与候选 Skill 七文件；四阶段沿同一个候选推演。摆位、节奏和拍法是导演提案，不补写人物关系、搬家原因或过去事件。

**1．Director Intent：一张照片，从待收的旧物变成暂时无法收起的承诺。**

观众先通过防尘布、整理照片的重复动作，以及两人隔着一段距离的对话，理解“这里正在被收拾，人准备离开”。开场不把照片拍成秘密证物；林的注意力首先是把事情做完，周的“留下来也没人看了”按日常回答处理，不演成责备。

关键变化分两步：周的“等等”先打断整理，让观众发现他对最后一张照片有特定的关注；翻面后，观众与林第一次获得完整文字，才理解这份关注涉及一个未能兑现的承诺。**悬念的答案是情感重量，不是隐藏事件。**

结尾要让观众看见：离开的现实没有变，但林处理这张照片的方式变了。她不把它收进相册，也不郑重宣布留下；照片只是暂时停在整理流程之外。最终体验是“他们曾经相信过，而现在只能承认曾经相信过”。

选定的表达政策：

- 注意力随林的整理、停手、阅读、另放展开；周保留主动提醒者的位置，不给他额外的“秘密反应”特写。
- 关键文字有一次完整、安静的阅读窗口；其余镜头优先保留两人的关系和动作后果。
- 不配煽情音乐，不朗读题字，不增添提示性声响。纸张、衣物与房间底声维持现实尺度。
- 表演变化主要落实在动作速度和完成方式上，不靠哭泣、苦笑或突然握紧照片替观众解释。

**实质替代：以共同空间为主的持续双人观察。** 从头到尾主要看周由窗边走到桌旁，以及两人最终并站；文字揭示仍须保证同步清楚。这会使“共同面对旧承诺”重于“林第一次发现”。代价是文字与面部、移动同时争夺注意；若专门移动摄影机靠近文字，又容易把揭示做成一个显著的摄影动作。本候选选择更明确地保障首次阅读，接受短暂离开面部表演的损失。

**2．Beat：四次变化，六个镜头承担。**

时间为约 40 秒的排演预算，不能靠抢台词或缩短阅读硬凑。

| Beat | 关键时点与行动 | 故事／观众认知变化 |
|---|---|---|
| 整理仍能照常进行，约 0—15 秒 | 两句开场对白；林翻过一张普通照片、放进相册，拿起最后的家庭合影，看一会儿，准备收进去 | 建立日常整理的规则。最后一张稍有停留，但观众尚无理由认定它藏着什么；周已知题字，林和观众未知。 |
| 整理被有意叫停，约 15—19 秒 | 周先转身：“等等。”林停手。周再说：“看看背面。” | 观众知道周希望她注意某项具体信息，但还不知道内容。林由收纳转为查验；此时不能提前演出读后的失落。 |
| 旧承诺进入当下，约 19—34 秒 | 林翻面，完整文字首次可读；她默读。随后周走近、看照片。林：“那时候我们真的这么想。”周看防尘布家具：“嗯。” | 题字将普通合影重新定义为过去的承诺。林的话确认当年的相信；周的目光把承诺与当下房间并置。“嗯”接受这句话，不成为改变离开决定的信号。 |
| 整理规则出现例外，约 34—40 秒 | 林翻回正面，轻放相册旁，松手；两人短暂沉默 | 不新增决定，而是以一次可见的行动区别对待这张照片。最后沉默承接这个例外，不另立一个没有触发事件的“情绪 Beat”。 |

**3．Blocking：让“准备收进去”和“最终没收进去”形成可见差别。**

空间暂按以下可执行假设：桌在客厅中部，林站桌南侧；窗在北侧，周起初面向窗外。盖布家具在桌的西侧，周靠近后可以直接转眼看见。实际房间尚无资产，这些方位只用于候选排演。

相册打开在林面前偏左，散照在手边，相册右侧留出一块桌面。关键家庭合影放在待整理照片的最后，正面朝上；不添加第二张同类家庭合影，也不指定合影人物身份。

- **建立整理动作。** 林问话时继续归拢照片，不抬头索要情绪回应。周望窗外回答。林随后翻过一张普通照片并放入相册；这次翻动不提供可读文字，也不作为线索强调。
- **让最后一张沿用同一去向。** 林拿起家庭合影，两手持边，不遮主要图像；看一会儿，再将照片移向相册。周此时转身说“等等”。林停在相册上方，照片尚未接触页面。“看看背面”说完后，她才翻。
- **第一次阅读。** 林把照片从相册上方略收回，移到自己面前的空位，两手沿照片边缘翻面。翻至背面朝上后，在桌面上方低位斜持，字的上端远离自己，供她自然俯读。周仍留在窗边，不在文字刚显露时走动。
- **周加入。** 林完成第一遍默读后，周从桌东侧走到她右侧，停在相邻但不接触的位置，看照片。他不接手、不指题字，也不通过一个得意或预知的表情强调“我早知道”。林仍看着照片说：“那时候我们真的这么想。”周随后转眼看西侧盖布家具，再说“嗯”。
- **结束动作。** 林在“嗯”之后翻回正面，移向相册右侧空位，接触桌面后松手。手离开照片，不抚摸、不再向相册移动。两人留在桌旁，不加拿行李、回望门口等新行动。

这里的选择是让周**等林第一次读完再走近**，以保护阅读窗口。另一种可行调度是他在翻面时开始走近，形成更连贯的共同靠近；代价是脚步与身体移动可能抢走观众对题字的注意，也更容易使林的发现看起来由周带领完成。

**4．Shot Plan：六镜，约 40 秒。**

所有机位保持在人物关系轴的同一侧；不靠跨轴或突然推近制造悬念。以下时间包括对白、动作与停留。

| 镜头 | 观众任务与实际构造 | 表演、声音、切点及邻镜接续 |
|---|---|---|
| **S1｜0—8 秒** | **理解正在收拾离开的房间。** 从桌东南侧拍固定中广景：林和桌在近处，周在窗边，盖布家具可辨。曝光保住周的身体姿态，窗外不成为视觉主体。桌上照片只作为整理对象，不读背面。 | 林：“这些都要带走吗？”周：“留下来也没人看了。”不留争执式对视。随后林翻过普通照片并放入相册。以这次收纳完成为切点，建立下一张原本也将被这样处理的预期。 |
| **S2｜8—15 秒** | **认出最后一张是旧家庭合影，看见它原本也将被收起。** 从林前方偏东拍中近景，保留脸、双手、相册开口；相机略高于桌面，照片正面处于可辨角度。无需逐一辨认合影人物。 | 她拿起合影，看约两秒，随后移向相册。保持任务性动作，不提前演成重大回忆。镜尾周在背景开始转身，转身方向引出下一镜；照片仍正面朝上、悬在相册上方。 |
| **S3｜15—19 秒** | **理解阻止来自周，而且他明确知道该看哪里。** 同侧较宽双人构图，同时容纳周转身与林持照片的手，避免只拍周、让停手动作消失。 | 周接续完成转身：“等等。”林立即停手；周：“看看背面。”两句间留出观众看清停手的时间。第二句说完，林开始把照片收回到面前；在尚未翻面时切出。无提前泄露文字的声画桥。 |
| **S4｜19—25 秒** | **与林一起第一次读到完整题字。** 林右肩上方的近距离俯视细节镜，保留少量肩部、双手和相册边缘，明确这是沿她的注意方向观看。照片占主要画面，题字平面清楚。开头仍见正面和翻转动作，随后才见完整背面。 | 接续上一镜的收回动作，翻面只发生一次。约一秒完成翻转，随后约五秒供阅读：**“我们一定会回到这里。——2006年夏”**。不加字幕替代实物文字，不朗读，不开始周的脚步。读后才切，下一镜负责面部后果；本镜不声称同时交付林的表情。 |
| **S5｜25—34 秒** | **把文字与现在的两人、房间联系起来。** 回到桌东南侧中景，林在近处，周从窗边走入她右侧；双人上身、仍持着的照片及西侧盖布家具共同在画面中。取足够景深，不用虚焦抹掉家具。 | 镜头开始后周才迈步，约两三步到桌旁，看照片。林：“那时候我们真的这么想。”不追问他，不要求对方安慰。周说话前先看盖布家具：“嗯。”说完保留短停顿，林仍持照片背面朝上。切在她开始最终处理动作之前。 |
| **S6｜34—40 秒** | **看清她主动把照片另放，而不是没来得及收。** 同侧更近、略高的双人中近景，画面必须同时包含林的手、打开的相册和右侧空位，并保留两人的脸。相册入口与落点之间有明确距离。固定机位，不在最后再推照片。 | 完整呈现：背面朝上 → 翻回正面 → 移到相册旁 → 落桌 → 松手。约三秒动作、三秒共同沉默；手离开后仍能看见照片正面朝上、独立于相册。以两人和这块桌面结束，不切空屋暗示他们已经离去。 |

**最关键、也最可争论的是 S4：用完整的文字细节镜，暂时放弃林第一次读到时的面部反应。**

选择它，是因为本场的转折必须建立在观众真正读懂整句话及日期上。如果先拍林的反应再补题字，观众会先知道“她被触动”，随后才得到原因，削弱源文本指定的同步发现。

真实替代是：**保持林的侧面中近景，让她的脸和斜持照片处于同一清晰范围，在同一个镜头里完成翻面与阅读。** 这样可以保住第一反应，发现更像正在眼前发生。代价是画幅、照片尺寸和持片角度都要同时迁就文字与脸；稍宽就读不清，稍窄又失去关系。当前没有资产与实际画面，不能声称这种构造一定成立，因此 E1 优先保障文字。

**由 Shot 返回 Blocking 的局部候选修订，已纳入上表：** 初步“在胸前翻过并阅读”的动作不足以保证肩上方机位能读清整行字。现改为“从相册上方收回，在桌面上方低位斜持，翻后稳定约五秒”，并把周迈步放在首次阅读之后。修改的是持片高度、倾角和动作间隔，不改谁先知道、不改台词、不改最终落点。

纸面复检范围为 S3—S5：S3 只收回、不翻；S4 接着翻且只翻一次；S5 起始仍为背面朝上，周此时才走近。首尾状态与对白顺序在文本上接得上。实际持片角度、自然程度和阅读速度仍待验证。

**5．专业 Review**

- **确定的文本冲突：本候选未发现。** 两句开场对白在 S1；最后合影及收纳意图在 S2；周转身、叫停、要求翻面在 S3；翻面先于完整文字揭示在 S4；默读之后周靠近、林说话、周看家具并回答在 S5；正面朝上另放及共同沉默在 S6。没有增加过去事件、合影人物身份或未来决定。周提前知情由明确提醒体现，不另加证明他的背景故事。
- **可信规划风险：** S4 五秒阅读可能显得“给观众展示道具”；S5 九秒容纳走近、两句对白和目光转移，余量有限；S6 若落点离相册太近，可能被理解为下一步仍会收进去。对应处理是保持林自然俯读、把窗桌距离设为两三步、确保落点与相册分离且松手后停住。以上是规划措施，尚不是效果证明。
- **需要媒体／观众验证的未知：** 实际画幅下完整手写字及日期能否一次读完；S4 的角度是否让人相信林也在同时看清；演员能否使提醒显得熟悉而非操控；观众能否将结尾读为“暂时不能按普通旧物处理”，而不是“决定不走”或“遗漏了一张”。现无人物、照片和场景资产，也未制作媒体，不能宣称这些已通过。

本候选最需要守住的是**翻面后的完整阅读，以及松手后的短暂停留**：前者让意义改变有依据，后者让“没有收进去”成为已经发生的行动。
