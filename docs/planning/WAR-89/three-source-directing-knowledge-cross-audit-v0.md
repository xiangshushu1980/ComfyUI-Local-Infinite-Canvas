## 4. 冲突、张力与不适用条件

| 审计发现 | 性质 | 推荐裁决（待批准） |
| --- | --- | --- |
| DirectorSKILL `editing-and-assembly.md` 的 Anti-slideshow 提议**每四镜至少一次换轴/方向**，但 `cinematic-language.md` 要求互动轴连续或可见重建 | **同一源内部的条件冲突**；不是必须强制换轴的导演定律 | **降低“每四镜”到诊断提醒**；镜头功能与观众空间理解优先。为了画面变化强行跨轴不采纳 |
| 固定 30°、两级景别变化、连续运动跨切、连续三镜时长差等数字准则 | 强启发式与创作例外的张力 | 保留“检查意外跳切/机械重复”的提问；**不放入 WAR-35/Engine 做不可例外的硬校验**，有意相似构图/静态对照可保留 |
| ViMax 倾向首镜最广、机位复用、移动过的机位不再复用；DS/TF 均允许有意从细节或反应开场、复用机位 | **源制作流程与导演表达目标冲突** | 导演的观众信息目标优先。ViMax 限制仅在采用其实际参考生成管线时作为局部执行策略 |
| ViMax Camera Tree 以父镜头“覆盖”子镜为参考关系；反打、新面部、手部特写可能根本没有相应像素 | **参考相似度 ≠ 视觉/空间证据** | 可继承 `missing_info` 识别方法；不把 `fully_covers` 当几何或图像实证。父机位关系、树无环归未来工程层；不替代 DirectorPlan 状态 |
| ViMax FF/Motion/LF 要静态首尾态；DS/TF 允许一镜连续表演、多 Beat、不需要显式首尾图片 | **表达形式不同，不是专业矛盾** | 强制**时间语义自洽**，不强制 FF/LF 图或字段；仅有执行转换需求时使用 VM-05—09 |
| 故意延迟揭示（TF/DS）与“让关键线索清楚可见”（TF-11、VM-02、DS-31）看似冲突 | **创作上真实的取舍** | 区分物理在画面、可辨认、观众注意到、角色知情四个层次。**揭示时点由 Intent 决定**，不能由可读性检查提前剧透 |
| Toonflow 字数/镜长阈值、DS 的 ASL/风险分数、ViMax `small/medium/large` 等 | **环境/对象不同，指标不可互换** | 借作时长/风险讨论线索，不作 H3 成功率、Beat 价值或自动验收阈值 |
| DS 的摄影“焦距心理学”、特定景深、世界光源与 H3 文本提示能力 | **专业设计与模型控制面不同** | Agent 可选表达意图；是否真实可由当前 Ref2VA 精准实现，记为待证。不可将焦距/灯比数值冒充已经校准的生成参数 |
| DS 原修复案例有“通过插镜/声音桥掩盖不匹配”策略；TF/DS 也要求道具与叙事事实真实连续 | **症状遮盖 vs 故事状态正确** | 插镜、声音桥可以改善观感，但**不得**让道具瞬移、台词失实、人物知情矛盾变成“审阅通过” |

这些应保留为**适用条件与优先级**，而不是把几套源资料简单称为互相错误。多数差异来自导演选择、AI 制作启发式、工程约束被混为同一层。

## 7. 决策示意：D《错过的钥匙》如何调用三源

**前提**（复用既有样本，不改变冻结故事）：希望观众先知晓钥匙 K，角色尚未注意。先确认该“观众提前知晓”的**导演意图**而非镜头技术自动决定。

1. **TF-02/11（观众信息）**：明确角色是否因视线/遮挡仍不知情，以及观众在哪个时点必须能识别 K。
2. **DS-07/10/12—16（表演/摄影）**：候选 A 保持人物关系镜、借纵深/调度让 K 可读；候选 B 插钥匙特写后回人物。A 保留表演和空间关系但 K 可能太小；B 提高提示强度但可能提前改变注意力/节奏。
3. **DS-17/20/21、TF-10（连续性）**：审核文件夹对 K 的遮挡、身体视线/相机视线、人物和道具实际起终态。
4. **VM-05—08（若需执行描述）**：才把选定 Shot 展开为真实初态→发生中的动作→完成的终态；不自行新造“人物已经发现 K”。
5. **Review**：文本逻辑可通过不表示 K 在最终媒体能被辨认。既有 WAR-72 低模指出小尺寸/遮挡风险；媒体证据缺失则保持待证，不擅自让 Engine 修创意。

在 C《没说出口》中同样可选“不切保留共同沉默”与“反应特写明示认知改变”；这首先是 Intent 的观众体验取舍，其次才是景别或技术限制。**这两例均属本次分析示意，不是新增实验**。

## 8. 交用户审阅的五项取舍
