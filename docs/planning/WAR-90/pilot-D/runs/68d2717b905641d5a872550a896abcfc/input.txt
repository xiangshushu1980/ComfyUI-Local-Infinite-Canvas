# 《错过的钥匙》
类型：现实主义短剧情
目标时长：约 35–40 秒
地点：一间小型办公室，傍晚
人物：林（男，30多岁）、周（女，30岁左右）

内景 · 办公室 · 傍晚

办公室里，一张长桌靠着墙，门在桌子的另一侧。桌上有一叠文件、一个蓝色文件夹和一把银色钥匙。

林站在桌前整理文件。周站在靠近门的位置，准备离开。

周：「钥匙呢？」

林：「刚才还在桌上。」

林低头寻找。他把桌上的文件挪到一边，露出那把银色钥匙。

周从门边向桌子走来。

林没有注意到钥匙已经露出来。他拿起蓝色文件夹，放到那叠文件上，文件夹恰好挡住了钥匙。

周走到桌旁，目光落在蓝色文件夹上。

周：「你刚刚是不是盖住了什么？」

林停下手里的动作。

他移开蓝色文件夹，钥匙重新露出来。

林看着钥匙，短暂沉默。

林：「找到了。」

周伸出右手。林拿起钥匙，将它交到周的右手中。

周握住钥匙，转身朝门口走去。

林留在桌边。

【已确认的创作意图】
这是一个关于注意力错位的小片段。
- 观众应该先于林发现钥匙已经出现。
- 林的整理动作无意间再次遮住钥匙，并非刻意隐藏。
- 周发现异常，是因为她看到了文件夹遮住桌面的位置，而不是因为她已经看见钥匙。
- 林重新发现钥匙后有一个短暂、略显尴尬的停顿；整体表演自然，不做夸张喜剧。
- 钥匙始终只有一把，最终由林交给周。

【空间与动作事实】
- 桌上的钥匙起初被文件遮挡。
- 林第一次挪开文件时，钥匙露出。
- 蓝色文件夹随后遮住钥匙。
- 林再次移开文件夹，钥匙重新露出。
- 林拿起钥匙并交给周，周右手接过。
- 周最终持钥匙朝门口离开，林留在桌边。
不得新增钥匙、改变钥匙位置、安排额外的交接动作，或改变人物发现信息的顺序。

【实验说明】创作意图属于确认的剧本资料，不是额外 Toonflow 导演规则；人物、环境与道具尚无真实图像资产。
