## 阅读时关注

- **故事理解**：故事发生什么、为什么发生，人物冲突、潜台词、情绪转折和观众知情状态是什么。
- **导演意图**：希望观众注意什么、何时知道信息、体验什么；这些是创作选择而不是简单镜头参数。
- **执行策略**：表演、Blocking、构图、剪辑、连续性；区分 Skill 明文规则、模型自选决定和实际验证结果。

> 中译本用于学习术语、结构与职责。原版路由中出现的未包含参考文件（如 Director's Book 模板、视觉类型资料），本次没有同时翻译；阅读时不要误以为三份学习文件覆盖两套项目的全部知识库。
