## 验证问题与边界

仅问：冻结 D 的 B2–B3 中，在长桌靠北墙、门在东墙、林在桌南侧、周从东侧门旁走向桌边、钥匙 K 不动的条件下，是否存在让 **摄影机在 K 首次露出时看见钥匙、周在全过程此前不看见、文件夹随后再次遮住 K** 的可执行方案？

要将三件事分开：**几何可见性**（人物/镜头到 K 的视线与遮挡）、**表演注意力**（林看得到也可以未注意到）、**镜头叙事效果**（观众能否在正确时点注意到 K）。可计算几何仅解决第一项，不自动证明后两项。

当前不测试 D 的 B4–B6、Shot08 精确交接、E 中文文字、全 38 秒剪辑或 H3 能力。任何本实验做出的机位或道具尺寸是派生假设，**不得写回冻结原始源文件**。

1. **定义最小空间状态：** 单位、北/东坐标系、桌的边界、门、K 坐标、文件与蓝色文件夹的位置/大小；林和周的头部/眼睛位置、周从门侧到桌侧至少三个关键姿态；摄影机候选位置和视角。所有未冻结值应标注「测试假设」。
2. **逐时态检验：** 初始文件遮挡 K；B2 文件移开，摄影机能见 K、周沿移动路径没有提前看见 K；B3 文件夹放下后摄影机/周见不到 K，周仍能注意文件夹的遮挡异常。分开检验「射线有无遮挡」「画幅里 K 是否够可辨」「林是否注意」。
3. **镜头连接：** 核对所选机位与当前 Step6/7 的景别、银幕左右、眼线、跨镜状态和 180°/30°规则有无可证矛盾；不要先验宣称空间已锁定。
