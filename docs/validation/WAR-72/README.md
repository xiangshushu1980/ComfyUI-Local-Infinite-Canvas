### 计算草图、几何假设及状态

世界坐标以米计，x 向东正、y 向北正；以下均为**派生测试尺寸**，不是 WAR-65 冻结事实：

```text
                    北 y+
   桌 x=[-1.10,+1.10], y=[0,+0.80]
   西侧文件堆     K=(-0.25,+0.45)          东侧
   ┌──────────────────────────┐
   │      文件/蓝夹 → K       │
   └──────────────────────────┘
       林=(+0.35,-0.45)         周终点=(+0.85,-0.35)
   相机B=(-1.60,-1.60)         ↖ 周路线（21个等距采样）
                                     门旁=(+2.00,-1.30)
```

桌高与 K 高度均暂用 0.76m；摄影机高度 1.55m，周眼睛高度 1.60m，林被简化为 x-y 平面半径 0.40m、z 从 0.85 到 1.75m 的直立圆柱（脚位固定）。钥匙假定约 0.06m 宽。周沿门旁→桌旁直线走；实际门位仍须与建筑平面核对。相机 A=(+1.55,-1.50)，相机 B=(-1.60,-1.60)，均不代表冻结摄影机。脚本完全公开了方程与采样点。

道具状态：T0 初始散文件覆盖 K；T1 文件向西挪开，文件堆仍在 K 西侧、不盖 K；T2 蓝夹搭在文件堆上向东伸出覆盖 K，K 不移动。文件/夹的平面覆盖矩形是假设，不是厚度、接触及道具摆放验证。

### 分时态可见性与镜头连接

**候选对照：**A 相机至 K 射线穿过林的有效遮挡体（最近平面距 0.1696m），因此**失败**；B 相机到林平面最短距离 0.9961m，故不被该模型遮挡；周到林遮挡轴最短平面距离跨 21 点为 0.3421–0.3750m，半径 0.40m 时全部遮挡。简3D 周→K 射线在林体轴最近处高度约 1.062–1.387m，落于所设圆柱高度范围；相机 B 也通过简3D 检验。人物关系动态轴线的相机 B 有向叉积符号全程一致（约 -3.555 至 -0.380），该 2D 路线无轴线翻转。

**最小修订与敏感性复检：**初始候选 A 摄影机位失败；不改人物、K、道具和路线，只将摄影机移至原 Step7 所建议的西南侧候选 B，重新检查同样的 21 点，模型通过。但有效身体半径 0.36m 时周的部分路径不再被遮挡，0.38m 时 21 点全通过；此结果说明需要约 0.375m 的最小有效横向遮挡半径，并非任何自然演员姿态都满足。人体姿态/手部动作/转身会改变遮挡体，不可把圆柱模型当作真人。

**镜头衔接：**原 Shot02 为西南侧较高 40mm MS、固定机位，Shot03 为西南侧约 1.5m 高 85mm ECU、固定机位；测试 B 的世界方位与候选区域相容，但未验证真实取景框、镜头工作距离、俯角与焦段。用 0.06m 钥匙及理想中心投影粗算，40mm 全画幅宽向约占画面 2.7%，**不代表观众一定能辨认**。Shot02→03 在冻结计划中 MS→ECU 为明显景别变化，当前没有发现必须跨越轴线的几何矛盾；实际两个机位不一定相同，仍须独立验证。T1→T2 必须拍出文件夹边缘跨过 K 的动作，不能只靠 T2 末态证明。

### Shot02→03 的构图限制

同一第一轮相机 B=(-1.60,-1.60,1.55) 至 K 的 3D 距离约 2.58m。40mm 全画幅 16:9 的理想平面水平视角约 48.46°、垂直视角约 28.41°；85mm 对应约 23.91°/13.59°。如果 40mm 镜头**中心严格瞄准林的脸**，从相机看 K 偏离中心约 **32.81°**，需要重新确定画框方向才有可能同时容纳人物和 K；不能把“相机有 K 的无遮挡光线”直接等同于“Shot02 同时读清人物和 K”。若镜头以 K 为中心，人物脸又可能被推离取景。原 Step7 标注的 MS + 40mm + 人物和 K 同时可读仍属**开放疑点**，Shot03 ECU + 85mm 应另设实际构图/机位后才判断切点与银幕方向。

**最小辅助方法门槛：**现在需要三维人体替身（独立头、躯干、肩臂及双眼点）、固定桌面与 K、两机位的实际画幅边界、移动轨迹和遮挡前后静帧/截图。这些事项用 Blender 简单低模就能验证，**ComfyUI 生成的图像不可作为几何遮挡证据**；它更适合在 Blender 验证后再检验观众能否看懂信息。由于用户要求启用 Blender/ComfyUI 需确认，本轮未调用两者，也未制作截图或媒体。

**阶段结论：**第一轮候选 B 被现实化躯干模型部分证伪；仅调整候选林脚位约 18cm 可在简化模型中恢复遮挡，是值得进入 Blender 低模的方案，但并非最终通过。WAR-72 继续 In Progress，下一步申请仅在隔离目录做 Blender CPU 低模、双眼射线检查和 Shot02/03 静帧，不改生产画布或原始 Skill。
