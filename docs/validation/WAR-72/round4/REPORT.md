2026-11-12 · Eric · D《错过的钥匙》B2–B3 · 独立派生验证，不更改 WAR-65 冻结剧本、Blocking、Shot Plan 或原始 Skill。

## 结论

**几何核心机制有条件成立，但完整自然表演与 Shot02 信息揭示仍未通过验证。** 本轮解决了第三轮低模的钥匙悬空、伸手距离过长、周终点过近三个主要问题，且依然保留周全程双眼遮挡与摄影机观察 K 的条件。但后续独立审计查出了右前臂与桌面相交；Shot02 中 K 的实际投影约27×9像素，不足以证明观众能识别。不得为了“通过”继续无记录地调整模型。

**安全边界**：仅 Windows Blender 5.2.3 LTS 后台、Cycles CPU、两线程、960×540静帧与网格几何检测。无H3、ComfyUI、GPU生成、其他剧本或生产代码修改。原第三轮 round3/ 全部只读保留。

## DirectorSKILL 机制与执行层的区分

**可以保留的导演构思**：存在具体三维代理姿态使“观众摄影视线无遮挡、周双眼被林挡住，随后蓝夹覆盖同一K”在离散位置成立，并且人体彩模可做到不发生林/周表面相交。这推翻了“前两轮遮挡必然不可行”的猜测，但不是对任何真人姿态的普遍结论。

**尚需导演／动作设计解决的工作**：林需要明显前倾，现有右前臂穿入桌面；蓝夹需由纸堆支撑且真实放稳；Shot02不能在“40mm MS同框人与桌”与“小钥匙足够显眼”之间凭摄影视线求交直接获得答案。没有证据证明冻结剧本不可拍，也不应把派生模型失败写回原Skill。

**剩余未证**：连续真人运动、目光及未注意的表演、文件夹稳定性、观众是否在Shot02自行认出K、镜头剪辑流畅度、H3生成表现。第四轮就此结束；按照失败允许收口规则，保存失败而不继续做候选C来追求通过。WAR-72仍 In Progress，是否另行执行更严格的物理姿态修订与Shot02信息实验由下一步决定。
