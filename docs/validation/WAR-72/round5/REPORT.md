# WAR-72 第五轮｜Shot02「观众先发现 K」摄影取景对照

2026-11-12；主机 Eric；仅研究 D《错过的钥匙》B2 的 Shot02（衔接 B3），CPU 低模和静帧。原 WAR-65 剧本、DirectorSKILL、Blocking、Shot Plan 均不修改，不运行 ComfyUI/H3/GPU。

## 结论

**原 40mm MS 镜头包含人物、桌面和周的接近关系，但钥匙非常小且部分被遮挡，不能证明观众在林之前识别到它。** F1 靠近的 40mm 能完整看到 K、林的头部和整理动作，同时让K更大，但让周完全脱框；F2 40mm 桌面优先继续放大K，却放弃人物面部关系；85mm ECU 的钥匙可见条件更强，但须增加/重新分配镜头覆盖，不能无声替换冻结计划。

这是一轮**几何、构图、静帧可见性**测试，不是真人观众识别测试；任何「可辨认」结论均只能标记未证。第四轮模型右前臂穿桌的问题保留，未动人体或道具。

## 画面内容与决策取舍

- **F0｜关系优先。** 林、桌、周的接近可以同框，空间信息最好；K 很小，末态仍有约1/3取样点被遮挡。镜头内林俯身、手臂及蓝夹可能引导观众注意其他地方，原 Shot02 的信息任务尚未证实。
- **F1｜动作＋钥匙。** 钥匙可见取样点达到9/9，投影较大，同时保留林头部与手。周已经出框，须依赖前后镜头或空间布置表达她从门边走来。这是折中假设，并非确定的最佳镜头。
- **F2｜桌面优先。** 钥匙增加到56×18px，可在同帧看到纸堆、手、文件夹的相对位置；同时失去林脸和周，不能完全承担原40mm MS的角色与注意力信息，手臂仍占较大面积。
- **F3｜85mm细节。** 钥匙形状明显更容易在静帧观察，但必须在B2内增加/替换镜头，重新分配八镜预算、信息停留时间和Shot03再次遮挡的切点。不得把「85mm能看清」等同于「原Shot02成功」。

**注意力与表演缺口：**低模人物没有真实眼神、脸部反应，未测林「看得见但未注意」的可信度；右前臂穿桌未解决；只渲染静态采样帧，未测6秒中观众何时观察到K、是否意识到蓝夹再遮住。不得把摄影视线、像素面积、模型自主观察或本报告作者的推断冒充真人识别率。

## 研究结论和待决

1. DirectorSKILL 的 Step5 原则已经指出道具必须可读；Step7 选择40mm MS在本低模中使 K 只有约27×9px、部分轮廓不可见，呈现**导演原则至具体镜头方案缺少可量化反馈**的问题。不能直接宣称原方案现实中必定失败，因为可通过道具尺寸/真实材质/焦距距离/表演重新验。
2. F1是最小的**单镜派生候选**：不增加镜头，改善K但牺牲周的画内可见。F2不能满足人物关系覆盖；F3虽然钥匙清楚，但本质是新增信息镜头，应另行考虑时长与剪辑预算。
3. 若要把「观众先看到K」从几何提升为叙事验证，必须由**不知道答案的独立观察者**按原960×540尺寸观看无遮挡/无放大的 T0→T1画面，并记录能否识别及答案位置；本轮只准备材料，不虚构任何参与者或成功率。
4. 不要继续为凑全通过而修改人体模型；已知右臂穿桌问题留在第四轮物理验证项。第五轮已完成设计取舍的可计算与静帧验证，WAR-72仍In Progress，不改原Skill，也不启动H3。
