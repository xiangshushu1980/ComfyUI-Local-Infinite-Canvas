## 3. 单一人工变化（用户审阅后方可冻结）

两个输入从同一份派生的 Sc1 Director Plan 得到。**只在 Sc1“注意事项”末尾增设同一个位置的一行“本轮导演关注重点（待确认的人工指示）”，其余所有字节一致。**这是本轮测试记录的编辑指令，不冒充原 Toonflow Schema 字段，也不回写历史 Director Plan。

- **A（基线候选）**：`本轮导演关注重点：观众关注陈说到“过年的时候……”时主动停住、未能问出口的克制；许的回应按已定剧本和规划保留。`
- **B（单点变体）**：`本轮导演关注重点：观众关注许已经察觉陈的未尽之言，却选择回避正面回答的瞬间；陈的停顿按已定剧本和规划保留。`

两者改变的仅是**观看重点**，不是“陈/许哪一方实际知道什么”的事实，也不授权改变已冻结的对白、表演禁忌、道具、场景及终态。若复制的 Director Plan 内已有语句与 B 的侧重点不兼容，先列明矛盾并返回用户审阅，不通过暗改其他字段让 B 显得更好。

## 4. 最小执行步骤（全属未来授权后的拟议行动）

1. **预检/冻结**：核对上述输入 SHA；记录确切源码文件、所选参考章节及版本。制作两份派生 Director Plan；用差异检查确认只改动上述一行。单独冻结两份实际提交给模型的 Storyboard 请求，除该行外保持逐字一致。记录模型名称/版本、推理强度/采样设置、工具/执行环境、固定规则、资产缺失与上下文；无法对齐的条件应阻止“受控”结论。
2. **两次隔离 Storyboard 文本回放**：以 Toonflow 原版 `storyboardTable.md` + 必要 `shotCraft.md` 规则为依据，依次在互不污染的独立上下文生成 A 与 B 各一份分镜表。**不运行上游 ScriptCraft 或重生成整个 Director Plan，不创建真实画布节点，不生成图片/视频。** 每份只调用一次；若失败，记录失败而不是无声明地重新抽样。
3. **结构与事实核查**：逐镜检查场次/事件覆盖、原台词零删改、角色与道具状态、空间/视线基础、时间与片段合计、分镜说明和缺素材标记。对纸面可检查项给出结论，不能用文本宣称 H3 可拍或观众真的感受到情绪。
4. **事件对齐的差异审阅**：按原剧本事件定位“陈停住 → 许看向陈并停顿 → 许回避回应 → 许离开”，不以 Shot 序号/镜数直接一一对应。逐事件比较镜头功能、主要视点、主体景别/裁切、听者反应是否有画面、停顿与镜头时长/切点、主次注意力是否落实。分别记录有意义的响应、仅文案变化、无响应、违背事实、无法判断。
5. **反馈与收口**：把 A/B 的相关原文及差异交用户审阅；结论仅限一次最小文本观察，不能归因于 Skill 必然规律或证明真实观众体验。向 WAR-59 提交可复用的导演审阅机制判断和未知，不直接开始 v0 设计。

## 5. 审阅与验收口径

| 核对问题 | 候选判据 | 不得声称 |
| --- | --- | --- |
| 输入控制 | 两份原始请求除了新增的一行指示外相同；模型/规则/环境记录相同 | 单次两路输出能排除模型随机性 |
| 剧本保真 | 全部台词与已确认情节事实、人物行为禁忌保持 | 更改关注点允许新增对话和背景 |
| 导演增量 | 镜头对主体、视角、切点、停顿/反应有可追溯且与 A/B 目标一致的实质区别 | Shot 多就一定更好 |
| 审阅可用 | 定位差异来自何项人工决定，能指出下游是否忽略或误解 | 观众已经理解、H3 一定可执行 |
| 失败处理 | 保留无响应/冲突/生成失败及未证项 | 只展示“最好看”的一组输出 |

**通过条件**：完成两路原始证据冻结、逐事件差异表、至少一个可解释的成功或失败观察、明确证据等级和用户审阅结论；没有响应或证明不了，也允许按研究目的成功收口。用户在模型执行前可提出对焦点词句、已知干扰或运行条件的修订。
