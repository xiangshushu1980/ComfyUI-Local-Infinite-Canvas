# 01-dialogue：四路人工案例对照

依据固定输入 `../../../inputs/01-dialogue.json`，比较同一批次 `01-dialogue/<组>/raw-output.txt`。这是单次文本 Prompt replay 的人工阅读，不是视频验收，也不据此排名。字段引文为原始输出摘录；画面与对白实际可执行性需要后续验证。

## 共同边界

四路都给出切镜理由；这些是计划中声明的观看重点，并不能证明切镜确实比单镜提供更好的观看效果。白杯多以字段或连续性说明保证，单人特写中未必可见；实际画面无法从文本确认。除上述时间压力、机位歧义、无图情况下的引用和细节补充外，本次未见明确的新增剧情证据。输入只有 Picture 1–3 的文字约束，所有参考图相关表述都应按此边界解读。
