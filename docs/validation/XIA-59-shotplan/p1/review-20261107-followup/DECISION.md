## 四类来源和评审边界

1. **输入 Beat 未定**：说话实际发声截断字、时间及图片几何和口播速度。原文提供全句不等于声波全句。
2. **P0 导演规划**：Native 时间紧、ViMax 含未量化“数秒”、Toonflow 内部对白与连续说明冲突；交杯角度/距离是规划目标。单样本不能归纳方法整体稳定性。
3. **P1 编译**：初稿省略的交杯细节已由 v2 部分补回；Toonflow v2 选择了不重复解释，Director v2 在 S1 额外具体化杯朝向并加入环境声。各自源、适配和限制均可追溯。
4. **H3 视频待验证**：视觉构图、手与杯、空间连续、口型、语速及跨镜音频；静态文字、规则检查和模拟均不等于视频验收。

## 供 XIA-52 / XIA-35 未来评审的最小信息候选（非 Schema）

| 需表达的信息 | 为什么 | 本次反例 |
|---|---|---|
| Action 的起点、动作、终点，主体/物体和动作前后状态，包括手别与归属变化 | 检查跨镜交接是否重复、丢失或镜像 | 交杯白杯须从 A 前经 A 右手移至 B 前由 B 左手持有，单写“杯子在场”不足。 |
| 剧本全文与实际发声片段、说话人、起止、被谁或何事打断、位置是否已知 | 完整台词不能推出实际听到全文或重复次数 | Toonflow 两镜全文 + 首镜完整说出 + 次镜又延续中断，缺少中断字和分句。 |
| Shot 时间窗、顺序、允许并行或先后、语音与停顿预算及其证据类型 | 检出必要时长与窗口不相容，保留条件假设 | 1.2 秒 7 字需要至少 5.83 字/秒；“数秒”无下界无法自动当作明确数值。 |
