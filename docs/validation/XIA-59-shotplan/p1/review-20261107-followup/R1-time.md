# R1：对白与动作时间预算

## 证据和计算

| 案例 | 镜头与源动作 | 对白及预算 | 判断 |
|---|---|---|---|
| Native S1 | 0–3.2 s，A 问话，B 短暂眼神接触 | A「你今天还好吗？」6 字，最多 3.2 s；可和视线动作重叠 | 字面无确定矛盾；实际起止和语气未测。 |
| Native S2 | 3.2–6.0 s，B 避视、吸气、嘴唇微动、停顿 | 无对白；2.8 s 内可安排动作，但先后与各自耗时未量化 | 不能按各动作时长简单相加；需表演测量。 |
| Native S3 | 6.0–7.2 s，B 转回看 A 并回答，A 听 | B「还好，只是有点累。」7 字 / 1.2 s = **至少约 5.83 字/秒**，假设整镜都用于发声；若转眼、起声或标点停顿占用独立时间则所需发声速度更高 | **潜在时间压力，不是数学证明不可能**；动作可与对白重叠，是否自然需指定口播、表演实测。P1 两稿沿用 6.0/7.2，属于继承，非新增缩时。 |
| Native S4 | 7.2–8.0 s，A 担心并沉默看 B | 0.8 s；神情变化可从 S3 末态开始 | **潜在感知压力**；0.8 s 并非形式矛盾，能否看清、是否足够需视觉与表演评审。 |
| ViMax S2 | 3.5–6.0 s，先看 A、垂眼、喉动，“停顿数秒后”回答 | 相同 7 字在 2.5 s 内；若把“数秒”按示例解释为 ≥2 s，剩余 ≤0.5 s，需 ≥14 字/秒；若按 ≥3 s 则仅停顿已超总时长；这些阈值均是条件假设，不是源文给出的数值 | **高风险时间预算；有条件的确定矛盾**：在明确要求停顿 ≥2.5 s 且对白为正时长时必不可能；源仅说“数秒”未给下界，不能单凭文字严格证明绝对不可能。P1 两稿保留了该冲突。 |

语速值仅是约束下限，不是假定的口播测量。P0 Director S2 的 3–5 秒包含停顿与同一句回答，亦有潜在时间压力；本次优先分析任务指定的 Native 和 ViMax。

## 最小修正候选（不覆盖原件，不宣称通过）

- **Native 规划候选 N1**：保持 4 镜和 0–8 s，把 S2/S3 切点从 6.0 移至 **5.4 s**，S3/S4 从 7.2 移至 **7.3 s**；S2 2.2 s，S3 1.9 s，S4 0.7 s。B 回答下限约 3.68 字/秒，但 A 反应更短；候选仅展示预算交换，**不是更优表演的证据**。必须分别调整 S2 末态与 S3 首态并保留吸气/停顿；口播及画面仍未验。若重视 A 反应，可改用跨镜声音连续的另一个候选，但那改变镜间音频安排并需单独设计。
- **ViMax 规划候选 V1**：保持切点 3.5/6.0 s 与 3 镜，把 S2 的“停顿数秒”改为“短暂停顿，具体时长待口播确定”，保留视线、喉动、完整对白。此处修改了源导演的停顿强度，**不是原样编译**；即便如此能否在 2.5 s 自然完成仍需测量。另一路可改变切点以提供更长预算，但应记录对其他镜头的影响。

候选是新导演选择和可复核的预算假设；不需要修改原始 P0，也不建议编译器默默修镜头。若为了比较规划稳定性而重跑 LLM，须另立目的、相同输入与模型配置、重复次数及停止规则；当前没有执行，也无需通过重跑判断这两个样本的原文。H3 实际时长、对白节奏、口型和画面表现须在真实参考图与另行批准的视频中验证。
