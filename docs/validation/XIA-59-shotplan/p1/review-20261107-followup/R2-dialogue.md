# R2：跨镜对白与被打断的导演选择

依据 [03 Beat](../../inputs/03-overlap.json)、[Toonflow P0](../../p0/batches/20261106-deepseek-offline/03-overlap/toonflow/raw-output.txt)、[P1 初稿](../03-overlap/toonflow/prompt.txt)、[P1 v2](../03-overlap/toonflow/prompt-v2.txt)、[冻结 Ref2VA 指南](../../upstream/h3/references/ref-en.txt)及[后补 base-en](../review-20261106/base-en-later-snapshot.txt)。后补文件不是原冻结快照，不能证明当时版本相同。

## 原始事实与冲突

Beat 给出的完整台词文本是 B 的「我以为你会留下来。」（8 个汉字）；同时要求 A 在 B 未说完时起身离开、B 发现后话音中断。Beat **没有指定观众听到的字、说话起止时间或中断字**。完整的剧本文字不等于一定完整发声，也不能从完整对白字段自动推断发声次数。

P0 s1 和 s2 的 `dialogue` 都保存完整句；s1 的 `state_out` 写“话语临近结束”，s2 的 `state_in` 写“仍在说话”，s2 动作又要求中断。`continuity_notes` 同时写“仅在 s1 完整说出”和“s2 为其话音延续与中断，不重复整句”：如果“完整说出”按完整声音解释，就与后续还在说同一句并在句中中断不一致。P1 初稿把冲突与两个全文字段写进提示；v2 保留第一次全文，第二镜写声音延续并中断，是选用“不重复”的**编译适配选择**，未确定具体发声片段，也未完整解决原冲突。它们不是原导演真实录音的证据。

## 两个新导演候选（均为假设，不是还原）

原句作为剧本元数据完整保留；以下“实际发声”仅为比较用的示例，不声称原始中断字是这些字。时间均是 **8 秒规划目标、未经口播测量**。

| | 候选 A：同镜中断 | 候选 B：跨镜中断 |
|---|---|---|
| 镜头 | 沿用 4.2 s 切点；将 A 真正起身提前到 S1 内（改变 P0 动作边界）。 | 沿用 4.2 s 切点；A 的重心转移跨镜，S2 起身，与原意较接近。 |
| 实际声画例 | S1 约 2.4 s B 开始说「我以为你会」；A 约 3.3 s 起身，B 注意后约 3.8 s 停声；S2 静默转身追视。 | S1 约 3.2 s B 说「我以为你会」，4.2 s 切镜时话音连续；S2 在约 4.3 s 继续发出「留」，约 4.6 s 看见 A 起身后戛然而止；后半句不发声。 |
| 新导演选择 | 假定被听到的字、起声和停止时刻，且改动 A 起身时机；不是源 P0 原样输出。 | 假定跨镜分句、实际听到「留」及发声起止时刻；不是源 P0 原样输出。 |
| H3 表达 | 同一句不跨镜，无须为这句使用 `<scenetrans>`；明确声音在镜内中断，不能把未说出的完整后半句作为发声指令。 | 同一句跨镜，依据后补指南在两个片段连接处使用 `<scenetrans>` 并明确声音跨切点连续；具体标记位置应依已确定的分句构造，并检查兼容性。 |

上述示例未直接生成 H3 最终 Prompt：本地 base-en 同时要求 `<d>` 仅含实际发声文本及逐字保留用户提供内容；完整剧本与截断口播的表示、片段标记的精确形式仍需单独确认，并不能把未经选择的 8 字全集直接视为两段实际声音。具体起止时刻也需受控口播验证。

`base-en` 第 142 行要求跨镜同一句在两部分连接点使用 `<scenetrans>` 并说明连续；`<cutoff>` 用于**视频结束时**话音被截断，不能用于这两个镜中被人物动作打断的候选。候选 A 改变了 A 起身的镜头位置；候选 B 具体拆字、实际发声及时间都属于新增导演选择。它们都应另立版本，不能覆盖原 P0 或解释为上游本来选定的方案。

## 分类和待测

- Beat 未定：实际发声内容、发声时机、中断字；P0 规划错误：字段重复与“先完整说出、又继续并中断”冲突；P1 编译：初稿带分析性元叙述，v2 删除重复并选择连续解释，非无损；H3 待测：是否按选定文本完成跨镜声音、表演及反应。
- 规则检查可发现互斥条件、重复字段和缺少分句；其不能决定哪个演出更好。另一次 LLM 试验只有在研究其能否在明确的口播契约下生成一致计划时有意义，须单独记录同模型条件和重复次数；并不能还原原始发声。真实发声需要口播，画面/音频/口型需要另行授权的真实 H3 视频验证。
