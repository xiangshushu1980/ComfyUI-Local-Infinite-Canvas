## 归因与判断

- 输入 Beat 未定：无真实 Picture 文件或量化几何、自然口播速度；P0 将机位 30–35° / 35–40°、约一前臂与抬头约 30° 写成计划，后又声明未测量。数字是目标而非空间事实，且“与桌面成角”和“近坐姿眼高”之间具体摄像机几何可能含糊，不能推定已校准或绝对矛盾。
- P0 导演规划：一次交接、手别、位置、首尾状态与切点被清楚写出；3 镜各时长是计划。源未声称实景效果。
- P1 编译：v2 相比初稿补回大量动作状态，但 S1 提前明确杯口向上、环境声补充、计划值缺少 Prompt 内可信度标记等都应单独记录；v2 为信息映射文本，不能称逐字段绝对无损或证明视觉结果。
- H3 待测：真实模型能否按图保持人物身份、杯子几何、手指、交接和声音；是否形成预期机位及表演、1.5 秒末镜是否自然。需要真实图文件/hash 与经另行批准的视频，不是静态报告可解决。

建议最小文字修订：在**实验元数据或审查说明**而非画面命令里标记数值是 P0 提议的未测量目标；如为严格逐镜事实，应将 S1 的 upright 位置去掉或标为跨镜连续推断，再审阅其与 S2 的关系。任何修改单独成候选并更新 hash，不能覆盖原件。没有因提升表现而改动源镜头、时间或手别。
