# XIA-59 P1：补全后审阅与案例差异（2026-11-07）

本次对其余 11 份 P0→H3 初稿逐镜核对了镜头配置、画面动作、blocking、起止状态与交接说明，针对初稿遗漏补回具体画面信息；加上此前交杯 Director 的 [v2](../02-handoff/director/prompt-v2.txt)，每组现有一份 v2。原 DeepSeek P0、Codex 初稿、原报告全部保留。版本与哈希位于各目录的 `metadata.json`、`metadata-v2.json`。本轮由同一 Codex 阅读来源、修订和复核，**不是独立双人盲审**，不声称逐字或全部内部字段无损。

补全用 `produce_v2.py` 把本次由 Codex 人工写定的逐镜英文补充放进原初稿，生成 11 个新版本；该脚本不调用 LLM。交杯 Director v2 由此前独立编辑。三条 Beat 直出 v2 只从生成正文移除“实验未提供原图”的元说明，Beat 原始来源与非盲测限制不变。环境声仍是编译默认值，非 P0 原始信息。

逐镜标记的判断是静态文本判断：**保留**指这次检查覆盖的镜头、时间、对白字面、关键行动/道具及指出的修订内容可追踪；不等于逐句翻译所有 rationale、uncertainties，也不证明模型能执行。各组仅一次样本，不是稳定性评估或胜率统计。

## 台词与可执行性

所有 03-overlap 样本的源事实都包含“完整句字段”和“说话中途停止”的张力，文本无法确定听众实际听到哪些字。v2 不是已解析这一冲突的最终 H3 执行指令，尤其 Toonflow 明确进行了上述适配。后补的 `base-en` 说明 `<scenetrans>` 需要在跨镜两部分连接点标记；由于这些源计划没有给出可复核的分句，v2 未凭空拆字、未声称满足该语法。`<cutoff>` 在该指南中指视频末尾截断，不用于本次句中被打断的事件。若未来需要可直接生成的视频 Prompt，应先把选中的源计划的实际发声内容明确化，并作为单独记录的源修订，不能把它伪装为原样编译。

## 验证与模型来源

15 个 v2 的六段标题顺序、镜头数/切点、源文件 SHA、输出 SHA 均通过脚本检查；12 份编译稿中 P0 的每句对白字面至少出现一次。检查未验证语义完整、对口型、跨镜音频及 H3 实际表现；Toonflow 的重复对白字段被适配，不能用“字面出现”掩盖这一事实。初稿和 v2 末尾都设为 8 秒，三个样本均未有真实图片文件输入。P0 是 `deepseek/deepseek-flash`、thinking off；P1 是本会话 Codex，后端具体版本未独立暴露；跨模型差异不得直接归因于 Skill 或导演方法。

用户允许必要时重做 P0；本轮没有为模型切换重做：源的台词冲突已可从原文定位，重复一次无法自动判定原样本的真实意图。本轮未使用 DeepSeek、Pi 或其他外部 LLM 代为生成；未运行 GPU、修改 Canvas 或 XIA-56。P2 仍需另行确认。
