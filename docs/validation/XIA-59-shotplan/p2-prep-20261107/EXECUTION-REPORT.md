## E2：同镜与跨镜中断

两个方案都把完整源句与本候选实际发声区分开，明确每个字、起止时点和中断因果。原剧本全文「我以为你会留下来。」作为来源元数据留在各文件顶部；`<d>` 只放候选实际可听文本。候选 A 在镜内中断，约 2.70–3.80s 说「我以为你会」，A 同镜开始起身后 B 停止；4.20s 后无对白。候选 B 于 3.20s 起声，切点 4.20s 前说「我以为你会」，越过切点仅接「留」，约 4.60s 看到 A 起身后停止，「下来。」不发声。候选 B 的声音跨切连续和拆字均是新导演决策，不是原 Toonflow 的已知实际发声。

静态 QC：两份 Prompt 均有官方兼容 Ref2VA 六段字段顺序；B=S1 一致；Picture→Subject 身份映射稳定；`<d>` 与实际发声选择一致；A 不需要跨镜连接标签，B 在切点连接两处都有 `<scenetrans>` 且文字说明连续；两份都没有 `<cutoff>`。完整源句不进入 `<d>` 作为发声指令。关于连接标签位置，依据是后补 `base-en-later-snapshot.txt` 对跨镜同句的明确文字；该文件不是已冻结 upstream 快照，故 P2 审批时仍应确认 H3 当前版本语法。静态语法通过不证明音频可执行。

## E3：交杯状态与编译保真

参照 `p1/review-20261107-followup/R3-fidelity.md`，在 DirectorSKILL P0→P1 初稿→v2 上核对：

- **明确源事实/规划**：杯唯一；交接前在 A 前、A 以右手推、B 以左手接；A 释放并撤手、B 在自己面前持杯；唯一归属变化 A→B；后续 B 左手持杯回答；切点 0–3.5 / 3.5–6.5 / 6.5–8 秒。
- **v2 保真点**：以上手别、动作和前后状态在文字中可追踪；没有指令再次递杯；S3 把 B 左手和杯放在画面中。初稿省略了部分起手、距离、撤手和角度细节，v2 作有记录补全。
- **推断/编译默认**：S1 “杯口朝上”是提前补充，源只在 S2 起点明确；约 30–40°机位、约一前臂推距、约 30°抬头都是 P0 的未测导演目标，不是 reference 几何测量。安静咖啡馆 room tone 与无非叙事音乐是 compiler default，不是 P0 源事实。引用 Subject 完全保留也是生成目标而非观察结果。
- **H3 待测**：是否只存在一个杯、手指和杯子接触连续、是否仅一次 A→B 归属变化、杯子是否静止停在 B 前、左右/轴线、对白与口型、1.5 秒末镜里 B 抬头和 A 微笑是否可读。静态保真不能证明任何一项成片成功。
- **建议小对照**：保留 Director v2 为复杂候选，和同一个 Beat 的“最小状态计划”比较。对照仍固定三镜/同切点/同三句对白/同一组必须保留状态；仅删未实测机位数值、相机细节和额外演出 elaboration，保留唯一杯、右手推、左手接、唯一 A→B 变化、A 撤手、B 最终持杯。它是提示复杂度诊断，不是把 Native/DirectorSKILL 按一个样本排名。E3-M 的新 prompt 应在用户审批后根据这些固定项另存并做 hash。
